# 🏎️ Oracle Red Bull Racing F1 Dashboard

A responsive Formula 1 themed Bootstrap dashboard inspired by the Oracle Red Bull Racing color scheme. This project was created as a Web Development activity using HTML, CSS, JavaScript, and Bootstrap 5.

---

## 📌 Features

- Responsive Bootstrap Navbar
- Formula 1 / Red Bull Racing themed UI
- Interactive dashboard cards
- Bootstrap Modal
- Validated feedback form
- Custom CSS styling
- JavaScript form validation
- Mobile responsive layout

---

## 🎨 Theme Inspiration

This project uses colors inspired by:

- Oracle Red Bull Racing
- Formula 1 race weekend dashboards
- F1 telemetry and lap time interfaces

### Main Colors
- Dark Navy Blue
- Racing Red
- Championship Yellow
